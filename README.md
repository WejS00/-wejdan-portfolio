# Wejdan's Portfolio

A bilingual (English & Arabic) professional portfolio website showcasing cybersecurity and technical projects.

## Live Preview
You can view the live site via GitHub Pages once enabled in the repository settings.

## Structure
- `index.html`: Main portfolio interface.
- `app.js` & `style.css`: Core logic and styling.
- `projects.json`: Project records and descriptions.
- PDF documents included for download.
